Política de Privacidade — Gestão de Estoque

Última atualização: 23/05/2026

Este aplicativo utiliza Firebase Authentication e Cloud Firestore para autenticação e armazenamento de dados.

Dados coletados

  • E-mail do usuário
  • Dados cadastrados no sistema

Uso das informações

  • Autenticação
  • Controle de estoque e vendas
  • Relatórios e histórico

Compartilhamento

Os dados não são vendidos nem compartilhados com terceiros, exceto serviços necessários para funcionamento do app.

Segurança

Os dados são protegidos utilizando os serviços do Firebase.
